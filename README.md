# Najah Reminder

Najah Reminder is a student-focused notification system designed to integrate with An-Najah National University’s Zajel platform. The project aims to deliver real-time updates and reminders for announcements, exam results, course registration, and other university notifications.

## Project Summary

This project is centered on improving the user experience for students, teachers, and staff by providing a faster, more reliable way to receive Zajel updates without manually checking the portal. It includes requirements, vision, scope, and use case documentation for a reminder and notification system.

## Key Goals

- Deliver real-time push notifications for Zajel updates
- Send reminder notifications when updates are not opened
- Support students, instructors, and university staff
- Improve information flow and reduce manual portal checks
- Respect university privacy and reliability expectations

## Main Features

- Real-time notification delivery from Zajel
- Reminder messages for unread notifications
- Update details displayed to the user
- Error handling when Zajel API is not available
- Notification retry queue for failed deliveries
